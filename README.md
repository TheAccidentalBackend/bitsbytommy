# Bits by Tommy

Personal website for [bitsbytommy.be](https://bitsbytommy.be).

## Technology

- Astro
- TypeScript
- Plain CSS
- Markdown or MDX for long-form content

The project will be built incrementally, keeping the site fast, accessible, and easy to maintain.

## Deployment

Cloudflare Workers builds and publishes the production site from the main branch.
